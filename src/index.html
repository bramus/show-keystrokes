Overview

Drop <key-stroke> anywhere on your page to visualize keystrokes as the user presses them, or set the keys attribute to render static keycaps in documentation.

<key-stroke></key-stroke>

<!-- Listen to all keystrokes -->

<!-- Static keycap display -->
<key-stroke keys="SHIFT + TAB" static></key-stroke>

Features

Configurable Keystroke Filters

Choose between shortcuts, navigation (default), all keystrokes, shortcuts only, or navigation keys only.

macOS & Windows Aware

Automatically adapts modifier names to macOS (CMD, SHIFT, ALT, CTRL) and Windows/Linux (CTRL, SHIFT, ALT, WIN), or override via platform.

Apple Keyboard & Mechanical Themes

Includes two built-in themes—Apple Keyboard (rounded squares) and Mechanical—each with Light and Dark variants.

Positioning, Sizes & Auto-Hide

Pin overlays to the viewport or pointer via position="top right" / position="pointer top right", scale across 5 presets (small to xx-large), and customize fade-out timeouts.

Installation & Setup

npm install key-stroke

Import the package to automatically register the <key-stroke> custom element:

import 'key-stroke';

Attributes & Configuration

Configure <key-stroke> declaratively using HTML attributes or dynamically via JavaScript properties.

Attribute Default Values / Description
filter "shortcuts, navigation" "shortcuts, navigation", "all", "shortcuts", or "navigation"
theme "apple" "apple" (Apple Keyboard) or "mechanical" (Mechanical Keyboard)
color-scheme "auto" "light", "dark", or "auto"
size "large" "small", "medium", "large", "x-large", or "xx-large" (or omit and set CSS font-size)
position Inline top/center/bottom combined with left/center/right (e.g. "top right"), optionally prefixed with pointer (e.g. "pointer top right", or "pointer" which defaults to pointer bottom right)
timeout 1500 Duration in milliseconds before the pressed keystroke starts fading out (0 disables auto-hide)
fade-duration 300 Duration in milliseconds of the fade-out transition (also aliased as fade-out)
platform "auto" "mac" (uses CMD), "windows" (uses CTRL), or "auto"

Filter Modes

Control which keystrokes are visualized using the filter attribute (defaults to "shortcuts, navigation").

Default: Shortcuts + Navigational filter="shortcuts, navigation"

Responds to shortcuts (CMD + A, SHIFT + ENTER) and navigation (→, TAB, SPACE, BACKSPACE, DELETE, F1–F15), ignoring plain typing.

Built-In Themes (Light & Dark Variants)

<key-stroke> ships with two built-in themes: Apple Keyboard (theme="apple") and Mechanical Keyboard (theme="mechanical"), each with both Light and Dark variants.

Theme 1 · Light

Apple Keyboard (Light)

theme="apple" color-scheme="light"

White rounded squares with grey text and subtle keycap elevation.

Theme 1 · Dark

Apple Keyboard (Dark)

theme="apple" color-scheme="dark"

Black rounded squares with lightgrey text mimicking backlit Apple keys.

Theme 2 · Light

Mechanical Keyboard (Light)

theme="mechanical" color-scheme="light"

Sculpted off-white keycaps with deep 3D keywell dish and slate modifier accents.

Theme 2 · Dark

Mechanical Keyboard (Dark)

theme="mechanical" color-scheme="dark"

Carbon keycaps with high-contrast legends and indigo modifier keycaps.

macOS vs. Windows Support

<key-stroke> automatically detects the user's operating system (using CMD on macOS and CTRL on Windows), or you can explicitly set platform="mac" or platform="windows".

JavaScript API

const el = document.querySelector('key-stroke');

// Programmatically display a keystroke
el.showKeys('SHIFT + TAB');
el.keys = 'CMD + A';

// Clear display
el.clear();

// Listen for keystroke events
el.addEventListener('keystroke', (e) => {
  console.log(e.detail.label);    // e.g. "SHIFT + TAB"
  console.log(e.detail.keys);     // e.g. ["SHIFT", "TAB"]
  console.log(e.detail.category); // "shortcut" | "navigation" | "keystroke"
});
