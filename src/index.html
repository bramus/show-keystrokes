<show-keystrokes>

GitHub npm

A zero-dependency custom element that visualizes live keystrokes, keyboard shortcuts (CMD + A, SHIFT + CMD + T, SHIFT + ENTER), and navigational keys (→, SHIFT + TAB) with macOS & Windows support and stylable themes.

Features

Configurable Keystroke Display

Choose what to show via show: Shortcuts & Navigational (default when omitted), all keystrokes, shortcuts only, navigational keys only, or none.

macOS & Windows Aware

Automatically adapts modifier names to macOS (CMD, SHIFT, ALT, CTRL) and Windows/Linux (CTRL, SHIFT, ALT, WIN), or override via platform.

Modern & Mechanical Themes

Includes two built-in themes—Modern (rounded squares) and Mechanical—each with Light and Dark variants.

Positioning, Sizes & Auto-Hide

Pin overlays to the viewport (default viewport top right), anchor to the pointer via position="pointer", or render in normal flow with position="normal".

Declarative HTML or create() API

Drop <show-keystrokes> directly into your HTML or dynamically instantiate and append it from JavaScript using create(options, parentElement).

Powered by Popovers

Renders viewport and pointer overlays in the browser’s Top Layer via the Popover API (.showPopover() / .hidePopover()) so keystrokes never suffer from z-index or stacking-context issues.

Installation & Setup

npm install show-keystrokes

Import the package to automatically register the <show-keystrokes> custom element:

import 'show-keystrokes';

Bookmarklet

Want to use <show-keystrokes> on any webpage without installing anything? Drag the bookmarklet button below to your browser’s toolbar. Clicking it on any page dynamically imports create from https://cdn.jsdelivr.net/npm/show-keystrokes and appends a <show-keystrokes> instance with the default positioning and theme applied.

Show Keystrokes ← Drag this button to your bookmarks toolbar 
if (!document.getElementById('show-keystrokes-bookmarklet')) {
  import('https://cdn.jsdelivr.net/npm/show-keystrokes')
    .then(({ create }) => create({ id: 'show-keystrokes-bookmarklet' }))
    .catch((err) => alert(`Failed to load show-keystrokes: ${err.message}`));
}

Attributes & Configuration

Configure <show-keystrokes> declaratively using HTML attributes or dynamically via JavaScript properties.

Attribute Default Values / Description
show (no value) (no value) (Shortcuts & Navigational), "all" (All keystrokes), "shortcuts" (Shortcuts only), "navigational" (Navigational Keys only), or "none" (Nothing)
theme "modern" "modern" (Modern Keyboard) or "mechanical" (Mechanical Keyboard)
color-scheme "auto" "light", "dark", or "auto"
size "large" "small", "medium", "large", "x-large", or "xx-large" (or omit and set CSS font-size)
position "viewport top right" "viewport" (or "viewport <top|center|bottom> <left|center|right>", defaults to viewport top right), "pointer" (or "pointer <top|center|bottom> <left|center|right>"), or "normal"
timeout 1500 Duration in milliseconds before the pressed keystroke starts fading out (0 disables auto-hide)
fade-duration 300 Duration in milliseconds of the fade-out transition (also aliased as fade-out)
platform "auto" "mac" (uses CMD), "windows" (uses CTRL), or "auto"
keys "" Keystroke string to display (e.g. "SHIFT + TAB", "CMD + A", "→"), also reflected via el.keys
static false Boolean attribute (and reflected el.static property) that renders static keycaps in normal document flow without attaching keyboard listeners or auto-hiding
disabled false Boolean attribute (and reflected el.disabled property) that disables the component and detaches all event listeners

macOS vs. Windows Support

<show-keystrokes> automatically detects the user's operating system (using CMD on macOS and CTRL on Windows), or you can explicitly set platform="mac" or platform="windows".

JavaScript API

import { create } from 'show-keystrokes';

// Dynamically create & append a <show-keystrokes> element
const el = create(
  {
    show: 'all',
    theme: 'modern',
    colorScheme: 'dark',
    size: 'large',
    position: 'viewport top right',
  },
  document.body
);

// Programmatically display a keystroke
el.showKeys('SHIFT + TAB');
el.keys = 'CMD + A';

// Enable or disable listening (reflects to the `disabled` attribute)
el.disabled = true;
el.disabled = false;

// Clear display
el.clear();

// Listen for keystroke events
el.addEventListener('keystroke', (e) => {
  console.log(e.detail.label);    // e.g. "SHIFT + TAB"
  console.log(e.detail.keys);     // e.g. ["SHIFT", "TAB"]
  console.log(e.detail.category); // "shortcut" | "navigation" | "keystroke"
});
