Overview

Drop <show-keystrokes> anywhere on your page to visualize keystrokes as the user presses them, or set the keys attribute to render static keycaps in documentation.

<!-- Live listener (defaults to showing shortcuts & navigational keys) -->
<show-keystrokes></show-keystrokes>

<!-- Show all keystrokes -->
<show-keystrokes show="all"></show-keystrokes>

<!-- Static keycap display -->
<show-keystrokes keys="SHIFT + TAB" static></show-keystrokes>

Features

Configurable Keystroke Display

Choose what to show via show: Shortcuts & Navigational (default when omitted), all keystrokes, shortcuts only, navigational keys only, or none.

macOS & Windows Aware

Automatically adapts modifier names to macOS (CMD, SHIFT, ALT, CTRL) and Windows/Linux (CTRL, SHIFT, ALT, WIN), or override via platform.

Modern & Mechanical Themes

Includes two built-in themes—Modern (rounded squares) and Mechanical—each with Light and Dark variants.

Positioning, Sizes & Auto-Hide

Pin overlays to the viewport or pointer via position="top right" / position="pointer top right", scale across 5 presets (small to xx-large), and customize fade-out timeouts.

Installation & Setup

npm install show-keystrokes

Import the package to automatically register the <show-keystrokes> custom element:

import 'show-keystrokes';

Attributes & Configuration

Configure <show-keystrokes> declaratively using HTML attributes or dynamically via JavaScript properties.

Attribute Default Values / Description
show (no value) (no value) (Shortcuts & Navigational), "all" (All keystrokes), "shortcuts" (Shortcuts only), "navigational" (Navigational Keys only), or "none" (Nothing)
theme "modern" "modern" (Modern Keyboard) or "mechanical" (Mechanical Keyboard)
color-scheme "auto" "light", "dark", or "auto"
size "large" "small", "medium", "large", "x-large", or "xx-large" (or omit and set CSS font-size)
position Inline top/center/bottom combined with left/center/right (e.g. "top right"), optionally prefixed with pointer (e.g. "pointer top right", or "pointer" which defaults to pointer bottom right)
timeout 1500 Duration in milliseconds before the pressed keystroke starts fading out (0 disables auto-hide)
fade-duration 300 Duration in milliseconds of the fade-out transition (also aliased as fade-out)
platform "auto" "mac" (uses CMD), "windows" (uses CTRL), or "auto"

Built-In Themes (Light & Dark Variants)

<show-keystrokes> ships with two built-in themes: Modern (theme="modern") and Mechanical Keyboard (theme="mechanical"), each with both Light and Dark variants.

Theme 1 · Light

Modern (Light)

Theme 1 · Dark

Modern (Dark)

macOS vs. Windows Support

<show-keystrokes> automatically detects the user's operating system (using CMD on macOS and CTRL on Windows), or you can explicitly set platform="mac" or platform="windows".

JavaScript API

const el = document.querySelector('show-keystrokes');

// Programmatically display a keystroke
el.showKeys('SHIFT + TAB');
el.keys = 'CMD + A';

// Clear display
el.clear();

// Listen for keystroke events
el.addEventListener('keystroke', (e) => {
  console.log(e.detail.label);    // e.g. "SHIFT + TAB"
  console.log(e.detail.keys);     // e.g. ["SHIFT", "TAB"]
  console.log(e.detail.category); // "shortcut" | "navigation" | "keystroke"
});
